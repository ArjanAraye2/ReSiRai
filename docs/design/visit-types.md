# عللِ مراجعه (نوعِ مراجعه) — نسخهٔ ۱ · مرجعِ داده

مالکیتِ محتوا: مهندسی (بر پایهٔ راهنمایِ بالینی) · بازبینیِ تخصصی در نسخه‌های بعدی.
قواعد: «سایر + فیلدِ توضیح» برایِ همهٔ تخصص‌ها، همیشه آخر. «مشترک» = بینِرشته‌ای (برایِ همهٔ تخصص‌ها لینک شود).

## مشترکِ بینِرشته‌ای (به همه لینک شود)
ویزیت/معاینه · پیگیری · تفسیرِ آزمایش · تفسیرِ تصویر · ارجاع · اورژانس/فوریت · سایر (توضیح)

## ساختارِ داده (پیش‌نویسِ اجرا)
- جدولِ رابطهٔ `tblStudyTypeSpecialties(StudyTypeID, SpecialtyID)` ← Many-Many.
- `tblRadiologyStudies.StudyTypeNote NVARCHAR(500)` ← توضیحِ «سایر».
- فیلتر: نوع‌هایِ تخصصِ پزشکِ مسئولِ مراجعه + مشترک‌ها + سایر؛ نمایشِ نوعِ قدیمیِ خارج از فهرست همیشه مجاز.
- باکسِ نوعِ مراجعه: autocomplete با فیلترِ همزمان با تایپ؛ اگر تایپ با هیچ گزینه‌ای نخورد → پیشنهادِ خودکارِ «سایر — توضیح بنویسید».
